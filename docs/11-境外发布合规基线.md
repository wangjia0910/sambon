## 1. 地域适用判定与复评闸门

### 1.1 法域边界（原文口径）

| 规范                       | 适用范围条款                                | 对境外版的结论                                                                  |
| ------------------------ | ------------------------------------- | ------------------------------------------------------------------------ |
| 算法推荐管理规定（网信办等四部门令第 9 号）  | §2「在中华人民共和国境内应用算法推荐技术提供互联网信息服务，适用本规定」 | 面向境外用户、境内无服务提供行为 → 备案（§24）、编号公示（§26）、安全评估（§27）不作为上线闸门                    |
| 区块链信息服务管理规定（网信办令第 3 号）   | §2「在中华人民共和国境内从事区块链信息服务，应当遵守本规定」       | 同上：备案（§11）、编号公示（§13）、日志留存（§17）不作为上线闸门                                    |
| 互联网信息服务管理办法（国务院令第 292 号） | ICP 备案经**境内接入服务商**提交                  | Cloudflare 境外接入无需 ICP                                                    |
| **《个人信息保护法》第 3 条（保留项）**  | 「在中华人民共和国境内处理自然人个人信息的活动，适用本法」         | **若运营、开发、客服或数据处理实际发生在境内，即使用户全在境外，仍可能适用 PIPL 与数据出境规则**，须单独评估；不因「面向海外」自动豁免 |

> 上述为法规文本的内部适用性分析，**不构成法律意见**；正式发布前须由目标市场执业律师与中国律师分别书面复核。方案 v1.0 中「备案回执为上线闸门」等表述为只读历史基线，按 D-12 覆盖，不改写原文。

### 1.2 「境外提供」必须同时成立的要件（逐条可核）

| #   | 要件                                                     | 证据形式                                | 不成立的后果            |
| --- | ------------------------------------------------------ | ----------------------------------- | ----------------- |

| G-4 | 不提供简体中文定向推广、人民币计价 / 境内支付、境内应用商店上架、境内客服或社群渠道            | 营销投放记录、支付通道清单、应用商店清单                | 触发复评              |

### 1.3 复评触发条件（任一命中即恢复 D-11 全链）

1. 向中国境内自然人开放注册、接单、结算，或对其定向推广 / 投放；
2. 在境内设立对外运营主体、部署服务器 / 节点、使用境内接入（含 ICP）；
3. 开通人民币计价、境内支付、境内应用商店上架或境内客服 / 社群渠道；
4. 滚动 30 天访问日志中中国境内 IP 占比 **> 5%**（**建议阈值，须由法务书面确认后方可作为正式口径**）；
5. 通过境内大模型 API 向境内用户输出，或引入境内内容分发 / 实名认证服务；
6. 监管机关书面认定适用，或法规 / 司法解释变更。

**触发后动作**：10 个工作日内由法务出具书面适用性意见 → 暂停新增境内用户 → 按 `docs/10` 的 V2-a / V2-b 恢复准备与申报 → 回写 `docs/07` §2 与本文版本。

### O-1 地域界定、运营主体与协议体系

- 法务出具《服务地域与适用法域意见》，与 §1.2 六要件逐条勾稽；
- ToS / AUP / Privacy Policy / Cookie Policy 上线版本齐备，明示服务地域、年龄门槛、管辖法律与争议解决、SBC 非资产条款、平台非劳动关系（方案 §6.5）；
- 若面向欧盟 / 英国用户且当地无设立，按 GDPR Art.27 / UK GDPR 指定书面代表并在隐私政策披露；
- 本地化：语言、货币、时区、日期与客服时区的目标市场适配（**发布前产品检查项，不改动演示原型**）；
- **量化验收**：一级页面协议入口覆盖率 **100%**；协议签署率 **100%**（沿用方案 §6.5）；版本与发布记录可回溯；主体名称在 ToS / 白皮书 / 支付协议 **3 处一致**。

### O-2 隐私政策与 Cookie / 同意管理

- GDPR Art.13/14 告知、合法性基础（Art.6）、数据最小化、目的限制、存储限制；权利闭环 Art.15–21；**响应时限 1 个月**（Art.12(3)，复杂情形可延长 2 个月并须在 1 个月内告知）；大规模画像 / 系统性监控触发 **DPIA**（Art.35）；
- **非必要 Cookie / 追踪前置 opt-in**，同意可随时撤回、同意记录留存；加州 CCPA/CPRA 提供「Do Not Sell or Share」并识别 **GPC** 信号；
- 数据泄露：向监管机构 **72 小时内**通知（Art.33），高风险的同步通知数据主体（Art.34）；
- **量化验收**：同意前加载的非必要 Cookie / 追踪脚本数 **= 0**；数据主体权利请求 30 天内闭环率 **100%**；72h 通知演练记录齐备；DPIA 结论签字。

### O-3 数据处理者协议与跨境传输

- 与 Cloudflare 及其他供应商签署 **DPA**，维护子处理者清单与数据流图（覆盖率 **100%**）；
- 传输依据：截至 **2026-11-12**，EU-US DPF（欧委会实施决定 (EU) 2023/1795）**仍有效**，但已受 2026-06-29 美国最高法院 *Trump v Slaughter* 与 EDPB 2026-07-31 致欧委会函影响，存在复审 / 诉讼压力 → **必须同时备 SCC (2021/914) + TIA + 补充措施（加密 / 假名化 / 密钥分离）作为回退**，不得单点依赖 DPF；UK 侧另核 UK Extension / IDTA；
- 留存期沿用方案 §5.3（业务流水 ≥ 3 年 / 埋点 180 天 / 定位 30 天），但须按 GDPR「存储限制」原则逐类复核并由法务签字；
- 若 §1.2 G-6 判定数据处理发生在境内，另附 PIPL 与数据出境路径结论；
- **量化验收**：数据流图覆盖全部子处理者；SCC 附件与 TIA 签署齐备；DPF 认证状态**季度复核记录**可查；回退切换演练 1 次通过。

### O-4 自动化决策、推荐透明度与 AI

- **GDPR Art.22**：对个人产生法律或类似重大影响的全自动决策须提供人工介入、异议与说明；项目契约 §10.3 已有「结算 / 争议 / 处罚人工兜底」，推送名单仍须提供可解释理由（`reason_codes`）与申诉通道，禁止全自动拒绝 / 封禁；
- **DSA**：若构成在线平台，Art.27 要求在 ToS 中说明推荐系统的主要参数及用户可控选项；Art.38 的非画像推荐选项**仅适用于 VLOP**，不得对非 VLOP 误报为强制；平台「关闭个性化 → 时间 + 距离中性排序」可作为该选项的实现口径；
- **EU AI Act Art.50 自 2026-08-02 起适用**：仅当用户直接对话式 AI 交互、或生成 / 操纵合成内容对外发布时触发标注义务；当前「规则引擎 + LLM 适配层（抽取 / 语义分 / 材料摘要，不面向用户生成内容）」**原则上不触发**，但一旦接入聊天助手或对外展示生成内容，须重新评估并做机器可读标记 / 显著披露；
- 账号级「关闭个性化推荐」开关由 P1 **提前至 P0**（依据改为 GDPR Art.22 / DSA Art.27，不再是中国算法规定 §17；D-06 排期结论不变）；权重版本公示 7 天、可复算可回滚；
- **量化验收**：关闭后个性化因子影响 **= 0**（F-09）；两个 `user_id` 分别开关互不影响；`reason_codes` 覆盖率 **100%**；若触发 Art.50，AI 交互 / 合成内容标注覆盖率 **100%**。

### O-5 SBC 非资产、支付、税务与制裁

- 白皮书与 ToS 明确 SBC 为平台内贡献积分凭证：**非加密资产、非证券、非支付工具，不可兑付 / 转让 / 场外交易，无收益承诺**；对外文案禁用 token / coin / 币 / 投资 / 收益 / 升值；对应 MiCA、FinCEN MSB、SEC Howey、FCA 的适用性出具书面界定（**结论须由目标市场律师签字，不由项目自行认定豁免**）；
- 赏金与充值走持牌支付机构托管（V3 不变）；KYC / AML、**OFAC / EU / UN 制裁名单筛查**覆盖全部发布方与接单人；
- 税务与平台报告：EU VAT / DAC7、US 1099-K、各市场销售税；劳动者分类风险（EU Platform Work Directive、California ABC test）与 ToS「非劳动关系」条款一并复核；
- **量化验收**：违规话术巡检命中即下线；制裁名单筛查覆盖率 **100%**；支付协议、税务登记与法务界定三件齐备；模型 / 规则不得直判资金结算（契约 §10.3）。

### O-6 未成年人、内容治理、安全与事件响应

- 年龄门槛：COPPA（美国 13 岁以下）、GDPR Art.8（成员国 13–16 岁）；考虑线下履约风险，**建议平台统一 18+**，并由法务书面确认；
- AUP + 违禁任务预检 + 举报入口 + notice-and-action；美国市场指定 **DMCA 版权代理**并公示联系方式；
- 第三方渗透测试无高危（V4）；安全与争议日志留存 **≥ 6 个月**（用途变为争议与安全，不再是中国区块链规定 §17）；72h 泄露通知演练；
- **量化验收**：未成年人拦截率 **100%**；举报 **24h 处置率 100%**；违规任务漏检率 **≤ 0.5%**（沿用方案 §6.4）；高危任务发布拦截率 **100%**。
