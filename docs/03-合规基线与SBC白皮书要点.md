## 1. SBC 白皮书 10 项要点（逐条评审）

逐项对应方案 §4.1.3，每项列「必须写明的内容 / 对应方案条款 / 缺失后果」。

### 要点 1 · 法律性质

- **必须写明的内容**：SBC 为平台内贡献积分凭证；非加密资产、非证券、非支付工具；不可兑付法币、不可转让、不可场外交易；不设二级市场；命名沿用 SBC 但不作代币化表述；无任何收益、增值、保值或投资回报承诺；赏金与充值走持牌支付机构托管。
- **对应方案条款**：§4.1.3 #1；§1.2「明确不做」；§4.1.1「不做」；§6.1（法务一票否决）；§7.3 G6；契约 §1、§10.1。
- **缺失后果**：构成积分代币化最高风险，法务一票否决；白皮书不予签字、G6 不通过、禁止上线；外部渠道违规话术巡检命中即下线。

### 要点 2 · 发行主体与治理

- **必须写明的内容**：运营主体；白皮书版本号 / 生效日 / 修订流程；唯一披露地址 `sambon.net/whitepaper`；历史版本归档；变更走「配置版本化 + 评审 + 公示」流程，禁止线上无留痕热改。
- **对应方案条款**：§4.1.3 #2；方案「阅读约定」（变更须配置版本化 + 评审 + 公示）；§4.2.2（权重变更公示 7 天）；§7.4 交付物清单；契约 §2 文件归属。
- **缺失后果**：披露主体与版本不可追溯，权重 / 规则变更留痕缺失；F-08「记录完整率 100%」不达标；无法证明「禁止线上无留痕热改」，G6 相关项不通过。

### 要点 3 · 总量与按有效完成铸造（年增发 ≤ 5%）

- **必须写明的内容**：初始总量（**方案未给定具体数值，须评审确定，本轮不自造**）；按「已有效完成任务」行为铸造，属贡献证明，非算力挖矿、非预付发行；年度增发上限 **≤ 5%**；每笔发行必须绑定真实 `task_id`。
- **对应方案条款**：§4.1.3 #3；§4.1.4（有效完成才转付）；§5.2 闭环铁律（不允许无任务来源的余额变化）；§0「有效完成」定义；契约 §5。
- **缺失后果**：出现无任务来源的余额变化，破坏「冻结 → 托管 → 转付一一对应 `task_id`」；账本对账差异 ≠ 0，G4 不通过；年度增发上限 ≤ 5% 无可校验口径。

### 要点 4 · 分配结构（70 / 10 / 15 / 5）

- **必须写明的内容**：初始分配比例 **接单人奖励 70% / 发布方激励 10% / 平台生态激励 15% / 风控与争议储备 5%**；调整须评审 + 公示 7 天。
- **对应方案条款**：§4.1.3 #4；§5.2 科目（生态激励 / 风控储备）；§4.1.4（高质量奖励、双向评价、邀请由生态激励支出）；契约 §5。
- **缺失后果**：奖励与储备来源无账面依据，结算一致性口径（孤立冻结 / 托管记录 = 0）被破坏；比例调整未公示 7 天，违反方案「阅读约定」与 §4.1.3 #4。

### 要点 5 · 获取规则与防刷

- **必须写明的内容**：获取途径（完成悬赏、双向评价、邀请、运营活动）及每类上限；方案 §4.1.4 完整版口径为双向评价 `+2 SBC / 次`（每日上限 3 次）、邀请 `+20 SBC / 有效新用户`（每月上限 200 SBC）；每类规则附防刷校验（关联关系排除、频次上限、异常检测）；违规刷单扣回所得、冻结账户、信用分降级、人工复核可申诉。
- **对应方案条款**：§4.1.3 #5；§4.1.4；§6.7；§4.1.5（赠送、补偿、邀请、活动奖励、争议中积分一律不计入用户榜）；契约 §5（**初版简化实现，未含邀请与双向评价奖励，仅保留核心科目与违规冲正**，差异已登记）。
- **缺失后果**：自交易刷积分、刷热度霸榜；作弊任务占比 > 0.5%、回溯重算覆盖 < 100%；用户榜「不计入项混入数 = 0」被破坏；命中契约 §10.3 人工兜底缺失。
- **阶段 B 法务倾向（定稿口径）**：用户榜 `net_sbc` 仅计「已验收通过任务的赏金本金」；评价 ≥ 4.5 的 +2% 高质量奖励由 `eco_incentive` 支出，**不计入 `net_sbc`**（方案 §4.1.5「防止刷榜」；理由见 `review/legal-review.md` §三.3）。本轮 `server.mjs:settleTask()` 已按此实现，白皮书须写明以消除「+2% 是否属活动奖励」的解释二义。

### 要点 6 · 消耗回收与有效期

- **必须写明的内容**：消耗与回收场景（发布悬赏冻结、平台内权益兑换、违规扣减、账户注销回收、年度销毁与通缩规则）；SBC 有效期与过期处理。
- **待评审项 D4**：方案 §7.5 D4 建议「设 12 个月滚动并提前 30 天提醒，写入白皮书」，**尚未拍板，本轮不作结论**；契约 §5 未定义有效期。
- **对应方案条款**：§4.1.3 #6（明确标注待评审项 D4）；§4.1.4（取消解冻、超时释放冻结、争议转托管、违规冲正）；§5.2 科目；契约 §5。
- **缺失后果**：D4 未写入白皮书 → §4.1.3 十项要素不齐，F-10 白皮书验收不通过、法务不予签字；注销回收规则缺失 → 删除权与账本留存最小化平衡无法闭环。
- **阶段 B 法务倾向（定稿口径）**：① 争议裁定 `refund_publisher` / `close`、取消、超时未成交时，**赏金与 5% 服务费全额原路退回**；仅在 `SETTLED` 时将 5% 服务费计入 `platform_revenue`（方案 §5.2「平台收入进入条件＝结算」；理由见 `review/legal-review.md` §三.4）。② **D4 维持「待评审」，本轮不设值、不作结论**，正式上线前由法务书面意见确定；若采纳有效期，须同时写入白皮书与用户协议（有效期、提前 30 天提醒、过期处理、注销回收），不得由格式条款单方缩短或无偿清零。

### 要点 7 · 双账本与锚定

- **必须写明的内容**：双账本模型（链下账本权威 / 链上存证校验）；锚定频率为每小时或每 1000 条流水（先到先触发）；上链内容为「流水摘要 + Merkle 根 + 时间戳 + 账本版本号 + 上一批次哈希」；零 PII、零任务正文；用户可在 `sambon.net` 查询自身流水哈希并校验；T+1 自动对账，差异立即告警并冻结相关结算；幂等与防双花；锚定覆盖率 ≥ 99.9%。
- **链选型**：许可链 / 联盟链（D1 待拍板，建议先用合规 BaaS）；**初版按契约 §0 / §10.6 仅做本地 Merkle 摘要 + 可插拔锚定接口演示，不接公链、不做真实锚定**。
- **对应方案条款**：§4.1.2；§4.1.3 #7；§4.1.6 验收（覆盖率 ≥ 99.9%、抽样 100 条用户侧校验通过率 100%、PII 命中数 = 0）；§5.1（`LedgerAnchored`）；§5.2 闭环铁律；契约 §4 事件清单、§10.6、§0。
- **缺失后果**：账本对账差异 ≠ 0 → G4 不通过、冻结次日放量；PII / 任务明文上链命中 ≠ 0 → 违反契约 §10.6 红线、一票否决；任一 `task_id` 全链路回放（成功率 100%）无法实现。

### 要点 8 · 权益映射且不得折现

- **必须写明的内容**：等级 → 权益（推送加权封顶总分 5%、可同时接单数上限、服务费减免、榜单展示位）；权益**不得折算现金、不得宣传增值**；自然排序不接受付费置顶，广告位独立分区并显著标注、不参与 RankScore。
- **对应方案条款**：§4.1.3 #8；§3.3（SBC 等级 / 榜单带来的推送加权封顶总分 5%）；§4.1.5 权益封顶；§4.2.2 口径规则；§4.1.6 验收（离线回放验证实际影响 ≤ 总分 5%）；契约 §6、§7。
- **缺失后果**：出现变现 / 折现通道 → 触及积分代币化红线（§6.1 一票否决）；付费污染自然排序 → 公平性验收（自然榜中广告位混入数 = 0）不通过。

### 要点 9 · 私钥与审计

- **必须写明的内容**：私钥 HSM / 多签管理、权限分级、异常冻结与应急、第三方审计与季度披露、灾备与迁移预案；普通用户不自持私钥（平台托管账户 + 链上地址映射）。
- **对应方案条款**：§4.1.3 #9；§4.1.1「不做」（不让普通用户自持私钥）；§4.1.6 优先级（第三方季度审计披露为 P2）；§5.3（导出与查询全量审计）；契约 §10.2。
- **缺失后果**：越权访问用例 ≠ 0、权限分级缺失 → §7.2 安全验收不通过；异常冻结缺失 → 违规交易线索 24h 内处置与争议全额托管无法执行。

### 要点 10 · 风险声明与备案

- **必须写明的内容**：反洗钱 / 反赌博 / 反传销、未成年人限制、税务说明、数据与隐私、区块链信息服务备案、算法备案、服务终止与积分处理预案。
- **对应方案条款**：§4.1.3 #10；§6（九类风险与一票否决清单）；§6.2（备案回执为上线闸门）；§7.3 G6；契约 §10.5。
- **缺失后果**：备案回执未取得 → 一票否决、G6 不通过；未成年人限制 / 举报通道不可用 → 一票否决；服务终止与积分处理预案缺失 → 注销与删除权无法闭环。
