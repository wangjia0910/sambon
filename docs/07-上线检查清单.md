## 附 B · 回滚触发线与范围（引用方案 §7.3）

- **回滚触发**：有效完成率环比下降 > 10%、争议率上升 > 1pp、账本差异 ≠ 0、违规任务漏检 > 0.5%、通知关闭率 > 2%。
- **回滚范围优先级**：算法权重版本 → 榜单权重版本 → 新功能开关 → 全量版本回退。
- 每级灰度（1 城 → 3 城 → 全量）必须复跑 G1–G7；G6 为一票否决清单全项通过的前置闸门。
