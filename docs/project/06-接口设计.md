## 1. 通用约定

### 1.1 基础路径与入口

| 项 | 口径 |
|---|---|
| Base | `/api`（全部端点形如 `/api/*`） |
| 运行时 | Cloudflare Pages Functions，路由入口 `functions/api/[[path]].js` → `dispatch(request, env)` |
| 未登记路径 | 一律 `404 NOT_FOUND`；SBC 转让/交易/兑付/收益类路径从未实现 |
| 静态页 | 主入口 `/`（用户版 web-client）、`/prod`（内部操作台）、`/index`（L0 演示）由 Pages 静态托管，不在 `ROUTES` 内 |

### 1.2 响应包络（`response.js`）

```json
// 成功
{ "ok": true, "data": <对象|null>, "error": null }
// 失败
{ "ok": false, "data": null, "error": { "code": "...", "message": "..." } }
```

- 统一响应头：`Content-Type: application/json; charset=utf-8`、`Cache-Control: no-store`、`X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer`、`X-Frame-Options: DENY`。
- 失败时不回显堆栈/SQL/PII：已知 `ApiFailure` 用其 `code`/`message`，未知异常统一 `INTERNAL_ERROR` / `500` / "服务内部错误，请稍后重试"。
- 幂等重放响应附加头 `X-Idempotent: replayed`。

### 1.3 会话与 CSRF（`auth.js`）

| 项 | 口径 |
|---|---|
| 会话 Cookie | `sambon_sid`，token 为 32 字节随机 hex；`HttpOnly; Secure; SameSite=Lax; Path=/; Max-Age=86400`（`COOKIE_SECURE=false` 可去 Secure，仅本地） |
| 服务端存储 | 仅存 `token_hash = SHA256(token)`；过期会话自动清理 |
| 口令 | PBKDF2-SHA256，默认 120000 轮，16 字节盐；只存派生值 |
| CSRF | 写操作需 JSON 返回的 `csrf_token` 回填到请求头 `X-CSRF-Token`；双提交校验；存在 `Origin` 头时校验同源，跨源拒绝（`CROSS_ORIGIN_BLOCKED` 403） |
| 公开写端点 | 注册、登录、匿名 `consents`、`admin/bootstrap` 免 CSRF；`verify-email` 凭令牌、`cron` 凭 `X-Cron-Secret` 在 handler 内独立鉴权 |
| 角色 RBAC | `publisher` / `solver` / `admin`；审核、推送、裁定、自动验收、风控处置、锚定、备份、运维仅 `admin` |

### 1.4 幂等（`withIdempotency`）

- 写请求体带 `event_id`（≤128 字符，客户端生成）。
- 首次：`idempotency.status=pending` → 业务在 D1 `batch` 事务内提交 → 置 `done` 并缓存 `{status,data}`。
- 重放：命中 `done` 直接返回缓存响应（`X-Idempotent: replayed`）；命中 `pending` 返回 `IDEMPOTENCY_IN_PROGRESS` 409；业务失败释放 pending 允许重试。

### 1.5 限流（`rateLimit`）

| Scope | 上限 | 适用 |
|---|---|---|
| `global` | 180 次/分钟 | 所有请求（入口统一） |
| `register` | 8 次/分钟 | 注册 |
| `login` | 10 次/分钟 | 登录 |
| `verify_email` | 20 次/分钟 | 邮箱验证 |
| `resend_verification` | 5 次/分钟 | 重发验证 |

- 窗口 60 秒；key = `scope:sha256(cf-connecting-ip|x-forwarded-for|UA).slice(0,32)`，不落明文 IP（`RATE_LIMIT_DISABLED=true` 仅本地关闭）。超限 `RATE_LIMITED` 429。

### 1.6 GPC / DNT 强制中性排序

- 浏览器信号 `Sec-GPC: 1` 或 `DNT: 1`：任一已登录请求进入时，服务端强制 `UPDATE users SET personalized_enabled=0, gpc_enabled=1`（账号级），后续榜单/推送走中性排序（时间+距离），忽略客户端传参。
- 关闭个性化为**账号级、服务端强制**（`account_level_preference:true`、`enforcement:'server_side'`），客户端不可覆盖。

### 1.7 `mode=demo` 降级（503）

- 未绑定 D1（`env.DB` 不可用）时为 `mode=demo`：仅 `GET /api/health`、`GET /api/config` 可用；其余端点返回 `503 PERSISTENCE_NOT_CONFIGURED`，明确提示绑定名为 `DB` 的 D1，不伪装生产可用。

### 1.8 错误码表

> 状态码按 `fail(code, message, status)` 第三参；未传则默认 400。下列为全部已登记错误码。

| 错误码 | HTTP | 含义 |
|---|---|---|
| `NOT_FOUND` | 404 | 资源或接口不存在 |
| `UNAUTHORIZED` | 401 | 未登录或会话失效 |
| `FORBIDDEN` | 403 | 角色/主体不符 |
| `CSRF_FAILED` | 403 | CSRF 校验失败 |
| `CROSS_ORIGIN_BLOCKED` | 403 | 跨源写请求被拒绝 |
| `RATE_LIMITED` | 429 | 请求过于频繁 |
| `BAD_BODY` | 400 | 请求体非合法 JSON |
| `BODY_TOO_LARGE` | 413 | 请求体超过 1 MB |
| `INVALID_EMAIL` / `DISPOSABLE_EMAIL` | 400 | 邮箱格式不合法 / 一次性邮箱 |
| `EMAIL_TAKEN` | 409 | 邮箱已注册 |
| `INVALID_PASSWORD` / `WEAK_PASSWORD` | 400 / 422 | 口令长度不合法 / 强度不足 |
| `INVALID_NAME` / `INVALID_ROLE` | 400 | 显示名 / 角色不合法 |
| `INVALID_CREDENTIALS` | 401 | 邮箱或密码错误（统一码防枚举） |
| `ACCOUNT_LOCKED` | 423 | 连续失败锁定 15 分钟 |
| `ADMIN_BOOTSTRAP_DISABLED` | 503 | 未配置引导令牌 |
| `INVALID_BOOTSTRAP_TOKEN` / `ADMIN_EXISTS` | 403 / 409 | 引导令牌无效 / 管理员已存在 |
| `INVALID_KIND` / `INVALID_FIELD` / `INVALID_LOCALE` | 400 | 同意类型 / 字段 / 语言不合法 |
| `MISSING_FIELD` / `MISSING_TOKEN` | 400 | 缺少必填字段 / 令牌 |
| `COMPLIANCE_BLOCKED` | 422 | 违禁词预检未通过 |
| `INVALID_BOUNTY` / `INSUFFICIENT_BALANCE` | 400 | 赏金非法 / 余额不足 |
| `ILLEGAL_TRANSITION` | 400 | 非法状态迁移 |
| `TASK_ALREADY_ACCEPTED` | 409 | 任务已被他人锁定 |
| `CONCURRENT_CONFLICT` | 409 | 并发抢单冲突 |
| `SOLVER_FILTERED` | 422 | 接单人被硬过滤拦截 |
| `NOT_ASSIGNED_SOLVER` | 403 | 非指派接单人 |
| `REJECT_LIMIT` | 400 | 驳回次数达上限（2 次） |
| `INVALID_DECISION` / `INVALID_ACTION` / `INVALID_RESOLUTION` | 400 | 判定/动作/裁定结果不合法 |
| `ACTIVE_TASKS_EXIST` | 409 | 存在进行中任务，拒绝注销 |
| `IDEMPOTENCY_IN_PROGRESS` | 409 | 同一 event_id 处理中 |
| `VERIFICATION_FAILED` | 400 | 邮箱验证失败（NOT_FOUND/INVALID/EXPIRED） |
| `CRON_DISABLED` / `INVALID_CRON_SECRET` | 503 / 403 | cron 未配置 / 密钥无效 |
| `FLAG_NOT_FOUND` | 404 | 风控标记不存在或已处置 |
| `PERSISTENCE_NOT_CONFIGURED` | 503 | 未绑定 D1（demo 模式） |
| `INTERNAL_ERROR` | 500 | 未知服务端错误 |

## 3. 核心端点详细规格

> 以下覆盖任务要求的核心端点。每个端点给出请求字段、响应 `data` 结构、副作用与错误分支。公开端点免 CSRF；其余写操作默认需 `X-CSRF-Token` 与（如适用）`event_id`。

### 3.1 `POST /api/auth/register`（公开）

**请求字段**

| 字段 | 类型 | 必填 | 校验 |
|---|---|---|---|
| `email` | string | 是 | 邮箱正则、≤254、非一次性域名 |
| `password` | string | 是 | 10–128 位；`ENFORCE_STRONG_PASSWORD=true` 时 ≥12 且 3 类字符 |
| `display_name` | string | 是 | 1–64 字符 |
| `role` | string | 是 | 仅 `publisher`/`solver` |
| `locale` | string | 否 | `zh-CN`/`en`，默认 `en` |

**响应 `data`**（201）：`{ user: UserView, session: {csrf_token}, verification_required: boolean, dev_token?: string }`；`Set-Cookie: sambon_sid=...`。

**副作用**：`users` 插入（初始额度由 `eco_incentive → user:*` 两腿记账，默认 1000 SBC）；`events(CreditChanged/NotificationQueued)`；`email_verifications` 令牌入库（仅摘要）；`notifications` 入队验证邮件。GPC/DNT 注册即关闭个性化。

**错误分支**：`INVALID_EMAIL` / `DISPOSABLE_EMAIL` / `INVALID_PASSWORD` / `WEAK_PASSWORD`(422) / `INVALID_NAME` / `INVALID_ROLE` / `EMAIL_TAKEN`(409) / `RATE_LIMITED`(429)。

### 3.2 `POST /api/auth/login`（公开）

**请求字段**：`email`（string，必填）、`password`（string，必填）。

**响应 `data`**（200）：`{ user: UserView, session:{csrf_token}, verification_required }`；`Set-Cookie`。

**副作用**：`risk.assessLogin()` 成功清零失败次数/`last_seen_at`，失败累加并在 5 次时锁定 15 分钟；创建会话。统一错误码防枚举。

**错误分支**：`INVALID_CREDENTIALS`(401) / `ACCOUNT_LOCKED`(423) / `RATE_LIMITED`(429)。

### 3.3 `GET /api/auth/me`

**请求**：无 body（需 `sambon_sid`）。

**响应 `data`**：`{ user: UserView, csrf_token, preferences:{personalized_enabled,locale}, verification_required, consents:[{kind,version,granted,created_at}] }`。

**副作用**：无（若请求带 GPC/DNT，入口中间件强制关闭个性化）。

**错误分支**：`UNAUTHORIZED`(401)。

### 3.4 `POST /api/tasks`（publisher/admin）

**请求字段**

| 字段 | 类型 | 必填 | 约束 |
|---|---|---|---|
| `title` / `description` / `category` / `bounty` / `acceptance_criteria` | — | 是 | `bounty` 为 0–1000000 正数 |
| `deadline_hours` | number | 否 | 1–720，默认 48 |
| `online` | boolean | 否 | 默认 true |
| `radius_km` | number | 否 | ≥0，默认 10 |
| `required_skills` | string[] | 否 | ≤20 项 |
| `difficulty` | number | 否 | 默认 0.3 |
| `contact` | string | 否 | **只用于生成虚拟号，原值丢弃不落库** |
| `event_id` | string | 否 | 幂等键 |

**响应 `data`**（201）：`{ task: TaskView(state=PENDING_REVIEW), compliance:{pass,hits,...}, rule_version }`。

**副作用**：违禁词预检（失败写 `RiskBlocked`）；LLM 结构化仅作 meta 提示（`model_decision:null`）；`tasks` 插入；`events(TaskPublished)`；发布风控评估（`assessNewTask`，只标记不拦截）；**不写账本、不冻结**。

**错误分支**：`MISSING_FIELD` / `COMPLIANCE_BLOCKED`(422) / `INVALID_BOUNTY` / `INSUFFICIENT_BALANCE` / `IDEMPOTENCY_IN_PROGRESS`(409)。

### 3.5 `GET /api/tasks`

**查询参数**：`?include_terminal=true`（默认 false，过滤 `REJECTED/CANCELLED/EXPIRED/CLOSED/DISCARDED/SETTLED`）。

**响应 `data`**：`{ count, tasks: TaskView[], include_terminal:boolean }`（最多 200 条，按 `created_at DESC`）。

**副作用**：无。

**错误分支**：`UNAUTHORIZED`(401)。

### 3.6 `POST /api/tasks/:id/review`（admin，人工闸门）

**请求字段**：`decision`：`approve`/`reject`（默认 approve）；`event_id`（幂等）。

**响应 `data`**：`{ task: TaskView, decision, rule_version }`。

**副作用**：`approve` → 冻结 `bounty+5%`（`user:发布者 -total` ↔ `subject:frozen +total`）、`state=PUBLISHED`、`frozen_total`、`events(CreditFrozen/TaskUpdated)`；`reject` → `state=REJECTED`、`events(TaskUpdated)`；两者均写 `audit_log(TASK_REVIEW_MANUAL)`。

**错误分支**：`ILLEGAL_TRANSITION` / `INSUFFICIENT_BALANCE` / `UNAUTHORIZED`/`FORBIDDEN`(403) / `IDEMPOTENCY_IN_PROGRESS`(409)。

### 3.7 `POST /api/tasks/:id/dispatch`（admin，人工闸门）

**请求字段**

| 字段 | 默认 | 约束 |
|---|---|---|
| `dry_run` | false | true 仅预览，不改状态 |
| `top_k` | 12 | 1–50 |
| `batch_size` | 8 | 1–50 |
| `expand` | true | 是否扩量 |
| `expand_to` | 30 | ≥1 |
| `supply_ratio` | 1.4 | 供需比 |
| `channel` | `platform_inbox` | 通道 |
| `event_id` | — | 幂等（非 dry_run） |

**响应 `data`**：`{ dry_run, task_id, state_unchanged, weight_version, algorithm_degraded, personalized, personalization_enforcement, mode, candidates[], filtered_out[], batches[], strategy, dispatch_id?, llm_hint, … }`。

**副作用**：非 dry_run → `state=DISPATCHING`、`dispatches` 落候选快照、`events(DispatchRequested/DispatchScored/DispatchSent)`、`audit_log(DISPATCH_CONFIRMED)`；账号级关闭个性化或任一候选关闭 → 整体 `neutralCandidates()`。

**错误分支**：`ILLEGAL_TRANSITION` / `FORBIDDEN`(403) / `IDEMPOTENCY_IN_PROGRESS`(409)。

### 3.8 `POST /api/tasks/:id/accept`（solver）

**请求字段**：`event_id`（幂等，可选）。

**响应 `data`**：`{ task: TaskView(state=ACCEPTED), escrow_total }`。

**副作用**：CAS 占位（`version` 条件更新）；`frozen → escrow` 托管腿；`solver_id`、`escrowed=1`、`stats.active_tasks+1`；`events(TaskAccepted/CreditChanged)`。

**错误分支**：`ILLEGAL_TRANSITION` / `TASK_ALREADY_ACCEPTED`(409) / `CONCURRENT_CONFLICT`(409) / `SOLVER_FILTERED`(422) / `FORBIDDEN`(403)。

### 3.9 `POST /api/tasks/:id/submit`

**请求字段**：`content`（string，≤20000，必填）、`event_id`。

**响应 `data`**：`{ task: TaskView(state=SUBMITTED, result_preview, result_pii_redacted), note }`。

**副作用**：`sanitizeSubmissionText()` 脱敏后写 `tasks.result_text`、`result_pii_redacted`、`submit_count+1`；`events(TaskSubmitted)`（含 `pii_redacted`、`redacted_count`）。原始明文不落库。

**错误分支**：`NOT_ASSIGNED_SOLVER`(403) / `ILLEGAL_TRANSITION` / `IDEMPOTENCY_IN_PROGRESS`(409)。

### 3.10 `POST /api/tasks/:id/verify`

**请求字段**：`decision`：`approve`/`reject`/`auto_accept`；`rating`（0–5，可选）；`reason`（可选）；`event_id`。

**响应 `data`**：approve/auto_accept → `{ task: TaskView(state=SETTLED), settlement }`；reject → `{ task: TaskView(state=IN_PROGRESS), decision }`。

**副作用**：approve → `settleTask()`（托管转付 + 5% 服务费入账 + 可选 +2% 质量奖励，写 5 类事件 + 审计）；reject → `reject_count+1`、回 `IN_PROGRESS`、`events(TaskVerified)`；auto_accept 仅 admin 可触发。`net_sbc` 只累加赏金本金。

**错误分支**：`ILLEGAL_TRANSITION`（仅 SUBMITTED） / `REJECT_LIMIT` / `FORBIDDEN`(403) / `INVALID_DECISION` / `IDEMPOTENCY_IN_PROGRESS`(409)。

### 3.11 `POST /api/tasks/:id/dispute`

**请求字段**：`action`：`open`/`resolve`（默认 open）；`reason`（≤500，open 时必填）；`resolution`：`pay_solver`/`refund_publisher`/`close`（resolve 时必填，默认 refund_publisher）；`event_id`。

**响应 `data`**：open → `{ task(state=DISPUTED), escrow_total, transferred:false, arbitration:'人工裁定…', model_decision:null, llm_summary }`；resolve → `{ task, resolution, arbitrator:'人工裁定', model_decision:null, llm_summary, llm_degraded }`。

**副作用**：open → `state=DISPUTED`、全额托管、`events(DisputeOpened)`；resolve（仅 admin）→ `pay_solver` 走结算编排，其余全额原路退回（含服务费）、`events(DisputeResolved/CreditChanged)`、审计 `DISPUTE_RESOLVED_MANUAL`。模型只输出材料摘要，`decision:null`。

**错误分支**：`FORBIDDEN`(403) / `ILLEGAL_TRANSITION` / `INVALID_RESOLUTION` / `INVALID_ACTION` / `IDEMPOTENCY_IN_PROGRESS`(409)。

### 3.12 `POST /api/tasks/:id/cancel`

**请求字段**：`reason`（≤200，默认 `publisher_withdrawn`）；`event_id`。

**响应 `data`**：`{ task: TaskView(state=REJECTED/CANCELLED), settlement|null, rule_version }`。

**副作用**：`PENDING_REVIEW` → `REJECTED`，`PUBLISHED/DISPATCHING` → `CANCELLED`；未托管 → 冻结全额原路退回；已托管 → `computeCancelSettlement`（90% 退发布方 + 10% 补偿接单人）；`events(TaskCancelled)` + 审计 `TASK_CANCEL_MANUAL`。

**错误分支**：`FORBIDDEN`(403) / `ILLEGAL_TRANSITION` / `IDEMPOTENCY_IN_PROGRESS`(409)。

### 3.13 `POST /api/tasks/:id/feedback`（solver）

**请求字段**：`kind`：`EXPOSED`/`IGNORED`（默认 EXPOSED）；`event_id`。

**响应 `data`**（201）：`{ task_id, kind, recorded:true, note }`。

**副作用**：仅写 `dispatch_feedback` + `events(DispatchExposed/DispatchIgnored)`；不改变推送名单与排序，仅用于疲劳度/热度统计。

**错误分支**：`ILLEGAL_TRANSITION`（仅 PUBLISHED/DISPATCHING） / `FORBIDDEN`(403) / `IDEMPOTENCY_IN_PROGRESS`(409)。

### 3.14 `GET /api/leaderboard/tasks`

**响应 `data`**：自然排序 → `{ rank_weight_version:'v1.0', weights, mode:'natural', personalized:true, items:[{rank,task_id,title,category,state,bounty,rank_score,factors,top_factors,disputed_discount}] }`；关闭个性化 → `{ mode:'neutral', rank_weight_version:'neutral', personalized:false, items:[{rank,…,rank_score:null,reason_codes:['NEUTRAL_TIME','NEUTRAL_DISTANCE']}] }`。

**副作用**：无。

**错误分支**：`UNAUTHORIZED`(401)。

### 3.15 `GET /api/leaderboard/users`

**响应 `data`**：`{ rank_weight_version:'v1.0', weights, note, items:[{rank,user_id,name,net_sbc,completed_count,weighted_rating,on_time_rate,rank_score,factors}] }`；四维权重 0.55/0.20/0.15/0.10；仅已验收通过的赏金本金计入 `net_sbc`。

**副作用**：无。

**错误分支**：`UNAUTHORIZED`(401)。

### 3.16 `GET /api/ledger/:userId`

**响应 `data`**：`{ user_id, entries:[{seq,event_id,task_id,account,delta,rule_version,memo,created_at,prev_hash,hash}], balance_check:{balanced,total_delta,note}, anchor:{anchor_id,merkle_root,leaf_count,pii_on_chain,task_body_on_chain,note} }`。

**副作用**：无（实时计算 Merkle 摘要，零 PII 上链）。

**错误分支**：`FORBIDDEN`(403，非本人且非 admin) / `NOT_FOUND`(404) / `UNAUTHORIZED`(401)。

### 3.17 `GET /api/events`

**查询参数**：`?task_id=`（可选，按任务升序最多 500 条；否则全流降序 200 条）。

**响应 `data`**：`{ count, events:[{seq,event_id,task_id,type,actor,payload,created_at}], registered_event_types: PROD_EVENTS }`。

**副作用**：无（payload 已白名单脱敏）。

**错误分支**：`UNAUTHORIZED`(401)。

### 3.18 `POST /api/preferences/personalized`

**响应 `data`**：`{ personalized_enabled, enforcement:'server_side', account_level:true, user_id, neutral_sort_rule }`。

**副作用**：`users.personalized_enabled` 更新（账号级）；`events(PreferenceChanged)`。

**错误分支**：`INVALID_FIELD` / `UNAUTHORIZED`(401) / `IDEMPOTENCY_IN_PROGRESS`(409)。

### 3.19 `POST /api/reports`

**响应 `data`**（201）：`{ report_id, status:'OPEN', note }`。

## 5. 人工闸门端点

> 结算、争议裁定、任务审核、账号处罚均为人工闸门；模型输出恒 `model_decision:null`，不直判。可见控件不等于授权，服务端强制校验。

| 端点 | 闸门类型 | 鉴权 | 是否自动执行 | 审计动作 |
|---|---|---|---|---|
| `POST /api/tasks/:id/review` | 任务审核 | `admin` + CSRF | 否，人工确认 | `TASK_REVIEW_MANUAL` |
| `POST /api/tasks/:id/dispatch` | 候选推送（含 dry_run） | `admin` + CSRF | 否，人工确认 | `DISPATCH_CONFIRMED` |
| `POST /api/tasks/:id/verify`（`approve`） | 验收结算 | 发布方本人 + CSRF | 否，人工确认 | `SETTLEMENT_CONFIRMED` |
| `POST /api/tasks/:id/verify`（`auto_accept`） | 超时自动验收（**手动触发**） | `admin` + CSRF | 否，仅 cron 出工单 | `AUTO_VERIFY_MANUAL` |
| `POST /api/tasks/:id/dispute`（`resolve`） | 争议裁定 | `admin` + CSRF | 否，人工确认 | `DISPUTE_RESOLVED_MANUAL` |
| `POST /api/admin/risk/resolve` | 风控处置 | `admin` + CSRF | 否，人工确认 | `RISK_RESOLVED_MANUAL` |
| `POST /api/admin/anchor` | 账本锚定 | `admin` + CSRF | 否，人工确认 | `LEDGER_ANCHOR_MANUAL` |
| `GET /api/admin/backup` | 备份导出 | `admin` | 否，人工确认 | `BACKUP_EXPORTED_MANUAL` |
| `POST /api/admin/cron` | 定时任务 | `X-Cron-Secret` | 只生成待人工确认工单，不自动结算/裁定 | `CRON_*` |

> `POST /api/admin/bootstrap` 凭 `ADMIN_BOOTSTRAP_TOKEN` 仅创建首名管理员；管理员已存在时返回 `ADMIN_EXISTS`(409)，不可重复引导。

## 6. 未登记路径与红线

| 项 | 口径 |
|---|---|
| 未登记路径 | 任何未出现在 `ROUTES` 的 `/api/*` 路径 → `404 NOT_FOUND` |
| 红线接口 | `/api/sbc/transfer`、`/api/sbc/trade`、`/api/sbc/redeem`、`/api/sbc/withdraw`、`/api/sbc/exchange`、`/api/sbc/yield`、`/api/sbc/market`、`/api/wallet/cashout` 等从未实现（`GET /api/config.red_lines` 公示） |
| 模型决策 | 所有端点响应中模型字段恒 `model_decision:null`；`GET /api/config.ai_disclosure` 披露六因子、降级状态与人工复核说明 |
| GDPR | `GET /api/me/export`（Art.15/20）、`DELETE /api/me`（Art.17，有在途任务拒绝） |
| 服务地域 | 境外发布合规基线 V2-O（`docs/11`）；本接口集不构成法律意见，正式发布以目标市场法务书面意见为准 |

> 本文所有路径、方法、字段、状态码均来自 `prod/lib/api.js` 的 `ROUTES` 与对应 handler，未编造端点或字段。本文不构成运营许可，正式发布以 `docs/13` §5 的外部证据与有权签字人书面 Go 决定为准。
